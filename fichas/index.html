Biblioteca de fichas

Consultando el catálogo…
Privacidad: GitHub Pages y los archivos de este repositorio son públicos. No subas fichas con teléfonos, identificaciones, placas, datos de Staff, información financiera ni otros datos confidenciales. Publica versiones depuradas o usa enlaces a Drive con acceso restringido.

Versiones y enlaces permanentes

El enlace general del portal permanece igual. Para una ficha concreta, comparte la liga que aparece al abrir su registro; seguirá apuntando al folio incluso si después se publica una versión nueva.

Aplicación generadora de fichas

Esta plataforma es el archivo de consulta. La herramienta donde se crean y editan las fichas sigue siendo independiente. Para publicar aquí una nueva versión de la herramienta, agrega el HTML aprobado a la carpeta fichas/herramienta y registra su enlace en catalogo.json.

Actualizar el archivo sin cambiar el enlace

1
Abre la carpeta fichas/archivo en GitHub e inicia sesión con tu cuenta autorizada.
2
Selecciona Add file → Upload files y agrega únicamente fichas depuradas y autorizadas para consulta pública.
3
Usa el nombre indicado abajo para que el portal identifique automáticamente folio, proyecto, fecha, tipo y versión.
4
Guarda con Commit changes. GitHub Pages actualizará el contenido. Pulsa Actualizar en este portal para recargar el catálogo.
DVM-EVT-2026-0001__HOT-CRUJI-BRAVO__2026-11-08__activacion__v1.pdf

Para publicar una revisión del mismo evento, conserva el folio y utiliza v2, v3… El portal ofrece la versión más alta y conserva el acceso a las anteriores.

Documentos privados

Para fichas internas con datos de personal, no utilices la carpeta pública. Mantén el archivo en almacenamiento con autenticación (por ejemplo, Google Drive de la agencia) y agrega únicamente su referencia aprobada al catálogo, respetando sus permisos. Un enlace público no protege la información aunque no aparezca en el listado.

Consulta por folio

Cuando una ficha tiene folio, la opción Compartir enlace genera una dirección que conserva ese folio y abre la versión más reciente publicada.

Esta web es de consulta. Para cargar archivos sin entrar a GitHub y manejar permisos privados, se necesitará un backend autenticado, por ejemplo Firebase, integrado en una siguiente etapa.
