# ÁGORA · Compras y Producción — Sitio web

Este repositorio contiene únicamente el frontend publicable de ÁGORA.

- Los expedientes, fotografías y presupuestos se guardan en IndexedDB del navegador que los creó, no en GitHub.
- Respaldar periódicamente los datos en formato JSON.
- Los botones de proveedores requieren un portal externo de recepción (Google Apps Script).
- Para autorizar Gmail, configurar la dirección del sitio publicada como origen JavaScript OAuth en Google Cloud.
- No subir claves OAuth privadas, tokens, expedientes o respaldos JSON al repositorio.
