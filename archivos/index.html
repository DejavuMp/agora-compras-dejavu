Vistas de artes / archivos de aplicaciónHasta 8 imágenes JPG, PNG o WEBP. Arte, mockup, plano o posición del diseño a imprimir.
Usa enlaces individuales a fotografías. No pegues aquí el enlace de una carpeta.
Evidencia del envío de archivosHasta 6 capturas de la carpeta compartida, listado de archivos o pantalla del material enviado por Drive.
Las imágenes se previsualizan automáticamente; el proveedor debe tener acceso a los archivos.
Fotografías por enlace: usa un enlace individual por imagen, no una carpeta. En Drive, revisa Compartir → Acceso general: para mostrar la miniatura a cualquier visitante necesitas permitir acceso con el enlace; para artes confidenciales puedes dar acceso solamente al correo del proveedor, aunque la vista previa pública podría no mostrarse. En ambos casos el proveedor podrá abrir el original si tiene permiso.
Evidencia documental: la herramienta reduce las capturas antes de subirlas. Para subir archivos directamente, Firebase Storage debe estar habilitado y el proyecto en plan Blaze. Si utilizas Spark, puedes añadir enlaces HTTPS de imágenes o compartir el material desde Drive.
El comprobante de recepción se genera cuando el destinatario confirma que tuvo acceso a los archivos. Publicar el enlace no demuestra por sí solo que el correo fue enviado. La publicación genera un enlace que no cambia. Si se solicita una corrección, usa «Publicar nueva versión»: el destinatario verá la versión actual y se conservará el historial.
