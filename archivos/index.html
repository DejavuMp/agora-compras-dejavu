Evidencia documental: la herramienta reduce las capturas antes de subirlas. Para subir archivos directamente, Firebase Storage debe estar habilitado y el proyecto en plan Blaze. Si utilizas Spark, puedes añadir enlaces HTTPS de imágenes o compartir el material desde Drive.
